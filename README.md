# Capstone Project — ProposalAI

A frontend AI engineering capstone project built during my FlyRank internship, focused on building AI-assisted development workflows.

## About

ProposalAI is an AI-powered tool that helps generate client proposals in minutes. This repo tracks the capstone build through the internship's weekly assignments, from initial setup to a deployed skeleton and beyond.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Dev tooling:** Cursor / Antigravity IDE (AI-assisted development)

## Project Structure

capstone-flyrank-next/
src/
app/ # routes (App Router)
components/ # shared UI components
public/ # static assets


## Status

**Week 3 — Capstone skeleton deployed.**

- Routed placeholder pages for every planned screen (Home, Dashboard, Proposals, Proposal detail, New proposal, Settings, Login, Signup, Health check)
- Tailwind design tokens set up
- Health-check route rendering live fetched data
- Connected to Vercel for automatic preview deployments on every push

## Getting Started

```bash
cd capstone-flyrank-next
npm install
npm run dev
```

App runs at `http://localhost:3000`.
